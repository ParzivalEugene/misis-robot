# 0002. Blender for visuals, primitives for physics

Status: accepted

## Context

The course includes 3D modelling. Mesh collisions in MuJoCo are less stable and less predictable
than primitive collisions, and masses and inertias from arbitrary meshes are hard to control.

## Decision

Blender produces visual meshes only. Each body in MJCF has invisible primitive geoms (box,
cylinder) that define collisions and inertia, and a mesh geom for appearance with no contacts and
no mass. The Blender model is generated by a script run headless. Units are meters, and each part
has its origin at its joint axis.

## Consequences

- Physics does not depend on appearance, so control work can start before the model is done.
- The Blender script is the source of truth for geometry, the `.blend` file is a build output.
- Visual and collision shapes must be kept in sync by dimensions shared through code.
