# Двухколёсный балансирующий робот в симуляции MuJoCo

Проект по курсу робототехники. Робот спроектирован в Blender, физическая модель и система
управления реализованы в MuJoCo на Python.

## Состав работы

- 3D-модель робота в Blender.
- Физическая модель в формате MJCF.
- ПИД-регулятор баланса и скорости.
- Сценарии: удержание равновесия, реакция на толчок, движение с заданной скоростью.
- Управление с клавиатуры.
- Индикация состояния цветом глаз.

## Запуск

Требуется [uv](https://docs.astral.sh/uv/).

```bash
uv sync
```
